## 摘要
大语言模型（LLMs）取得了显著进展，但其巨大的存储和内存带宽需求仍阻碍着高效部署。权重二值化是一种有前景的解决方案，但现有的基于二值化的后训练量化（PTQ）方法通常因隐藏开销而远超名义上的1比特存储目标。为解决这一差距，我们提出了All for 1-Bit（AF1），一个真正用于LLMs的1比特PTQ框架。AF1包含两个互补组件：（1）零空间感知二值分解（NABF），通过基于Hessian的代理重参数化、零空间感知二值分解和仅缩放全局重构来改进二值重构；以及（2）层次Shapley分配（HiSA），使用层次Shapley敏感性分配结构容量。二者共同在PTQ设置下严格的1.0-BPW预算内保持模型精度。在LLaMA、Qwen和Gemma系列上的实验表明，AF1在困惑度和零样本准确率上持续优于现有的基于二值化的PTQ方法。与BF16相比，AF1在评估模型上平均实现2.5倍推理加速和超过90%的内存减少，为LLMs的可部署真正1比特压缩提供了实用路径。用于复现的代码可在https://github.com/Kishon-zzx/AF1获取。

## Abstract
Large language models (LLMs) have achieved remarkable progress, yet their massive storage and memory-bandwidth demands still hinder efficient deployment. Weight binarization is a promising solution, but existing binarization-based post-training quantization (PTQ) methods usually far exceed the nominal 1-bit storage target due to hidden overhead. To address this gap, we propose All for 1-Bit (AF1), a genuine 1-bit PTQ framework for LLMs. AF1 comprises two complementary components: (1) Null-space-Aware Binary Factorization (NABF) for improving binary reconstruction through Hessian-aware surrogate reparameterization, null-space-aware binary factorization, and scale-only global reconstruction; and (2) Hierarchical Shapley Allocation (HiSA) for assigning structural capacity using hierarchical Shapley sensitivity. Together, they preserve model accuracy under a strict 1.0-BPW budget in the PTQ setting. Experiments on LLaMA, Qwen, and Gemma families show that AF1 consistently outperforms existing binarization-based PTQ methods in perplexity and zero-shot accuracy. Compared with BF16, AF1 achieves an average 2.5 times inference speedup and over 90% memory reduction across evaluated models, providing a practical path toward deployable genuine 1-bit compression for LLMs. The code for reproducibility is available at https://github.com/Kishon-zzx/AF1.

## 一、论文核心问题与整体含义（研究动机与背景）

大语言模型（LLMs）近年来快速发展，参数规模不断攀升，如 LLaMA-3.1-405B、Qwen3.5-397B-A17B 等已达到数百亿乃至数千亿参数。在 BF16/FP16 精度下，仅模型权重就需存储数百 GB，加上 KV cache 和中间激活，推理部署的内存与带宽开销已成为严重瓶颈。

权重量化是缓解该瓶颈的关键路径之一。其中**权重二值化**（将权重表示为 {−1, +1}）理论上可将存储降至单比特量级，并支持比特级运算，极具潜力。然而，论文指出当前研究存在一个核心矛盾：

- 现有**基于二值化的 PTQ 方法**（如 BiLLM、ARB-LLM、HBLLM 等）通过 Hessian 信息识别显著权重并分配额外存储，但引入了大量辅助元数据（缩放因子、分组参数、bitmap、掩码等），导致端到端有效比特位宽（effective-BPW）远超名义上的 1-bit，实际落入 2~4-bit 区间。
- 现有**量化感知训练（QAT）方法**（如 OneBit）虽能实现真正的 1-bit 表示，但依赖大规模训练数据、长优化周期和庞大算力，难以大规模推广。

因此，论文的核心研究问题即为：**能否在 PTQ 设定下实现严格意义上的、无大量额外元数据的“真正的”1-bit 权重压缩，同时保持模型精度？**

针对这一目标，该论文提出了 **All for 1-Bit (AF1)** 框架，首次系统性地解决了现有方法中两个根本缺陷：
1. 单矩阵二值化参数化导致表示能力不足，难以捕捉 LLM 权重的复杂幅值和结构相关性；
2. LLM 不同结构单元对二值化误差高度异构，统一配置无法实现最优容量分配。

## 二、论文方法论

AF1 的总体框架集成两个互补组件：

### 1. Null-space-Aware Binary Factorization (NABF)

NABF 用于提升二值重构精度，包含三个子步骤：

**（a）Hessian 感知的代理重参数化**

直接按均方重建误差优化会平等对待所有权重扰动，忽略了不同权重对损失的影响差异。NABF 基于 K-FAC 启发的对角近似，利用输入激活统计量 \( \mathbf{i} \) 和输出梯度统计量 \( \mathbf{o} \) 构造 Hessian 加权代理矩阵：

- \( i_j = \sqrt{E[x_j^2]} \)，其中 \( x \) 为输入激活；
- \( o_u = \sqrt{E[g_u^2]} \)，其中 \( g = \partial L / \partial Y \) 为输出梯度；
- 权重矩阵重参数化为 \( \mathbf{W}' = \mathbf{o} \odot \mathbf{W} \odot \mathbf{i}^\top \)，将 Hessian 加权重构转化为代理空间中的 Frobenius 范数目标。

**（b）零空间感知的二值 ADMM 分解**

在代理权重矩阵 \( \mathbf{W}' \) 上，采用双因子二值参数化：

\[
\mathbf{W}' \approx (\mathbf{a} \odot \mathbf{A}_{\pm} \odot \mathbf{m}_1^\top) (\mathbf{m}_2 \odot \mathbf{B}_{\pm} \odot \mathbf{b}^\top)
\]

其中 \( \mathbf{A}_{\pm} \)、\( \mathbf{B}_{\pm} \) 为二值符号矩阵，\( \{\mathbf{a}, \mathbf{m}_1, \mathbf{m}_2, \mathbf{b}\} \) 为连续缩放向量。分解通过 ADMM 交替优化进行：固定一个因子，对连续代理进行 SVID 投影回到二值缩放域。每次 SVID 投影会引入离散残差 \( \mathbf{E}_A \)，该残差经固定因子传播后造成输出扰动。

NABF 的核心创新在于**利用零空间抑制离散投影误差**：若将残差 \( \mathbf{E}_A \) 投影到固定因子 \( \mathbf{B} \) 的近似左零空间中，则 \( \mathbf{E}_A \mathbf{B} \approx 0 \)，投影误差在前向传播中几乎被消除。论文通过固定因子的非中心协方差矩阵 \( \mathbf{C}_B = \mathbf{B}\mathbf{B}^\top \) 的 SVD 分解，选取低能尾随奇异向量构造近似零空间投影器 \( \mathbf{P}_B \)，补偿后的目标定义为 \( \mathbf{A}_{\text{target}} = \hat{\mathbf{A}} - \mathbf{E}_A \mathbf{P}_B \)。最后通过最小二乘的闭式解计算校正向量 \( \gamma^* \)，将其折入中间缩放向量（\( \mathbf{m}_1 \leftarrow \mathbf{m}_1 \odot \gamma^* \)），不使用任何额外稠密参数，也不改变推理计算图。

**（c）仅缩放全局重构**

冻结所有二值符号矩阵后，仅通过连续缩放参数（\( \mathbf{a}, \mathbf{m}, \mathbf{b} \)）进行全局校正。利用小规模校准集，以全精度模型作为教师，通过最小化 KL 散度（教师与学生 logits 之间的分布匹配）对各层的缩放向量进行梯度优化。

### 2. Hierarchical Shapley Allocation (HiSA)

HiSA 从博弈论视角分配有限的结构容量，分为两个层级：

**（a）层级的粗粒度分配：渐进式 Shapley**

考虑所有 Transformer 层，目标是为每层分配不同中间维度。通过 Monte Carlo 排列采样，从全容量状态开始依次降级各层到代理维度，记录 NLL 增量作为 Shapley 边际贡献，最终用温度控制的 Softmax 将层重要性分数转换为层预算。该方法能够捕捉误差的跨层传播和非加性交互效应。

**（b）模块级细粒度分配：双灵敏度 Shapley**

对于每个 Transformer 层内的注意力/前馈子模块，分别计算两种互补失真：
- **方向失真 \( r_{\text{dir}} \)**：衡量余弦方向的角漂移；
- **幅度失真 \( r_{\text{mag}} \)**：衡量相对幅值/能量的漂移。

分别用 Monte Carlo 排列估计两种失真下的 Shapley 值，经 MAD 鲁棒 Z-score 归一化后，通过 Soft-OR 规则融合（避免某一失败模式被平均掩盖），最后通过尺寸感知平滑密度公式将层预算细分到每个子模块，并将预算转化为 NABF 使用的中间维度 \( r_i \)。

### 3. 严格 1.0 有效 BPW 控制

与现有方法不同，AF1 对单层矩阵的部署存储进行数学上可控的约束。采用双二值因子结构，二进制位仅用于两个符号矩阵（\( \mathbf{A}_{\pm} \) 与 \( \mathbf{B}_{\pm} \)），连续参数仅有 3 个轻量缩放向量（以 BF16 保存），无 mask、bitmap、显著列索引、稀疏索引等任何额外结构开销。模型级有效 BPW 对目标线性权重严格为 1.0。

## 七、优点

1. **真正的“1-bit”承诺**：与之前标称 1-bit 但实际存储 2~4 BPW 的工作不同，AF1 从数学上严格控制了部署时存储，且不依赖任何训练/重训，是真正意义的 1-bit PTQ 方案。
2. **零空间技巧在二值量化中的创新应用**：将零空间的概念引入离散投影误差抑制，通过在缩放向量中吸收误差而非增加额外结构，设计巧妙且保持了推理结构不变。
3. **方法理论支撑完整**：附录包含双因子二值化表示能力的严格证明（提供反例说明单因子不可表达的模式）、近似零空间投影性质证明、闭式解推导等，方法解释性较强。
4. **用 Shapley 刻画跨层交互**：HiSA 相比于局部敏感性方法（逐层/逐模块独立测量），能更好地捕捉误差的相互作用和非线性传播。通过“双灵敏度”（方向 + 幅度）的拆分也提供了细粒度结构容量分配依据。
5. **实验设计公平且较为严谨**：报告有效 BPW 而非名义 BPW 的做法值得肯定；消融实验覆盖细致（每种方法三四个关键超参数都做了多模型验证）。
6. **部署定位明确**：不仅报 PPL 和 benchmark 精度，还给出了实际推理吞吐、内存占用、模型文件大小等工程指标，并报告了量化的时间开销。

## 八、不足与局限

1. **仅权重压缩，未覆盖激活和 KV cache**：论文明确的限制是只针对目标线性层权重的 1-bit 压缩。在长上下文或大批量服务场景下，激活和 KV cache 可能成为更大的瓶颈。这意味着论文中的端到端加速与内存收益在极限部署场景下会被稀释。

## 八、不足与局限（续）

2. **效率评估的代表性有限**：推理效率对比（图 5）仅涉及 BF16、GPTQ-W4 与 AF1 三种配置，缺乏与同为二值化方法（如 BiLLM、HBLLM）的端到端延迟对比；且仅在 3 个模型上测量，未覆盖所有实验模型。此外，论文未深入分析 1-bit 权重在真实硬件（如 CPU、移动端或专用加速器）上的算子实现效率。

3. **存储计算口径的边界值得注意**：论文报告“模型文件仅 2.92 GB”及“内存降低约 90%”时，只针对权重文件或者目标线性层的参数存储；若包含嵌入层（embedding）、输出层（LM head）、LayerNorm、KV cache 和激活，端到端的模型体积削减比例会明显低于权重层面的 90%。论文在方法层面对 1.0 BPW 的数学界定是严谨的，但在工程层面的“模型压缩率”表述读者需要注意其统计口径。

4. **校准集规模与领域迁移风险**：虽然论文做了样本数与随机种子的敏感性分析，但所有校准数据来自 RedPajama/C4 这一类通用语料。对于法律、医疗、金融代码等高度专业化的下游领域，仅 128 条通用序列能否充分刻画 Hessian 统计尚缺乏验证。

5. **7 个零样本任务的文化与语言偏向**：全部以英文任务为主，未在中文等多语言场景（如 C-Eval、CMMLU）进行验证。考虑到 Qwen3 与 Gemma 的多语言特性，缺失多语言评测是覆盖面的一个遗憾。

6. **大模型上的评测细节不完整**：虽然主实验覆盖了 70B 级模型，但对于 70B 及更大大模型的逐层 HiSA Shapley 计算开销并未报告（只在 7B 级模型上报告了端到端量化时间）。Shapley 本身依赖 Monte Carlo 排列采样，层数越多、排列越多，计算成本随层数增长明显，论文未明确给出大规模模型上的扩展性分析。

7. **对向量量化/低比特生态的衔接不足**：AF1 的 1-bit 权重如何与常见的 4-bit/8-bit KV cache、激活量化等方案协同部署，论文未给出组合实验。如果激活保持 BF16，则实际推理中访存瓶颈仍由激活主导时，1-bit 权重优势的发挥条件需要进一步说明。

## 九、潜在改进方向与研究展望

1. **扩展到联合量化**：将 NABF 的零空间思想拓展到激活与 KV cache 的量化中，实现真正端到端统一的极限压缩；
2. **硬件协同设计**：针对 1-bit 权重的矩阵乘法设计专用 kernel 与算子（如基于 popcount 的 XNOR 计算），与当前英伟达 GPU 的 Tensor Core 适配，或向 CPU/移动端移植验证；
3. **自适应 Bit 分配与多精度兼容**：在 NABF 框架内引入逐层或者逐模块的位宽选择，使 AF1 同时支持从 1-bit 到 4-bit 的平滑切换，以便根据硬件和精度需求弹性部署；
4. **扩大评测面**：补充多语言任务、长上下文任务、多模态模型的验证，并在更多 QAT 方法（如 OneBit 的大模型适配版）上比较；
5. **理解 1-bit 模型的表示极限**：论文指出了单因子参数化的反例，但对于多大模型规模、多少训练数据下 1-bit 权重能逼近全精度的理论边界仍无清晰刻画，值得后续工作做模型缩放率（scaling law）层面的探索。

## 十、总结性评价

总体来看，AF1 是本领域一篇方法创新性强、工程考量完备的工作。它同时解决了“语义上的 1-bit”与“存储上的假 1-bit”之间的错位问题，在 PTQ 设定下提出了不亚于甚至超过部分 QAT 方案的精度表现。NABF 的零空间补偿机制从数学上提供了一个漂亮且实用的误差抑制思路；HiSA 的 Shapley 分配框架则为异构容量分配提供了博弈论层面的一般性工具。虽然其存储统计口径、评测覆盖面和部署协同等问题尚需在后续工作中补足，但就“在无训练条件下实现真正 1-bit 权重压缩”这一目标而言，该工作无疑向前推进了重要一步，也为后续极限低比特量化研究提供了新的基准与方法参照。
