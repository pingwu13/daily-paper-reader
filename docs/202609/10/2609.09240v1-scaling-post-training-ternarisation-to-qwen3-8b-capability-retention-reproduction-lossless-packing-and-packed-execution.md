## 摘要
超低位宽语言模型有望减少存储和内存流量，但名义上的“1.58 比特”标签并未说明实际部署表示或其执行成本。我们研究了将一种激进的后训练转换流水线从 Qwen3-4B 扩展到 Qwen3-8B。该转换在仅权重的 A16 配置中使用了 KOTMS 旋转、E2M-ATQ 自适应三值化以及 GPTQ 风格的误差补偿。我们不声称这些算法是新的。我们的贡献是端到端的扩展刻画：外部复现门控、匹配的 4B/8B 能力分析、跨语料库困惑度、有效比特核算、无损的格感知打包，以及直接打包执行。8B 模型达到 1.361 倍的三语料库困惑度比，其中 WikiText-2、C4 和 PTB 的比值分别为 1.318 倍、1.393 倍和 1.371 倍。在 n = 500 的八个零样本任务上，平均准确率为 64.6%，而 FP16 为 72.4%，对应 78.5% 的经机会校正保持率和 7.8 个百分点的绝对代价。匹配的 4B 运行保持 69.6%，从而带来 8.9 个百分点的 8B 优势。打包后的检查点为 8.24 GiB，并在测量精度内保持了所记录的困惑度。直接打包执行在 7.35 GiB 下达到 15.52 tokens/s，而初步的打包 GEMV 仍慢于 FP16 cuBLAS。该结果是一个经过验证的扩展基线：模型规模提升了对激进后训练离散化的鲁棒性，针对所测量产物的实际序列化问题已得到解决，且直接执行可行，而更广泛的随机种子、校准分布和内核优化仍有待探索。

## Abstract
Ultra-low-bit language models promise reductions in storage and memory traffic, but a nominal "1.58-bit" label does not specify the deployed representation or its execution cost. We study a scale-up of an aggressive post-training conversion pipeline from Qwen3-4B to Qwen3-8B.   The conversion uses KOTMS rotation, E2M-ATQ adaptive ternarisation, and GPTQ-style error compensation in a weight-only A16 configuration. We do not claim these algorithms as new. Our contribution is the end-to-end scale-up characterisation: an external reproduction gate, matched 4B/8B capability analysis, cross-corpus perplexity, effective-bit accounting, lossless lattice-aware packing, and direct packed execution.   The 8B model reaches a three-corpus perplexity ratio of 1.361x, with WikiText-2, C4, and PTB ratios of 1.318x, 1.393x, and 1.371x. On eight zero-shot tasks at n = 500, mean accuracy is 64.6% versus 72.4% for FP16, corresponding to 78.5% chance-corrected retention and a 7.8-point absolute cost. The matched 4B run retains 69.6%, yielding an 8.9-point 8B advantage.   The packed checkpoint is 8.24 GiB and preserves the recorded perplexity to measurement precision. Direct packed execution reaches 15.52 tokens/s in 7.35 GiB, while a preliminary packed GEMV remains slower than FP16 cuBLAS. The result is a validated scale-up baseline: model size improves robustness to aggressive post-training discretisation, actual serialisation is solved for the measured artefact, and direct execution is feasible, while broader seeds, calibration distributions, and kernel optimisation remain open.

- **问题起点**：超低位宽语言模型承诺降低存储与内存流量，但"1.58-bit"这一名义标签并不说明**实际部署表示**（部署到磁盘/显存中的真实格式）与**执行成本**（是否能被高效运行）。
- **三重脱节**：
  - 表示层面：单个三值符号信息量 `log2(3) ≈ 1.585` bit，但完整 checkpoint 还包含自适应残差平面、偏移、缩放、掩码、旋转信息、嵌入、LM head 与元数据。
  - 能力层面：原生低位模型是"围绕低位表示训练"，而 PTQ 关心的是"已预训练模型在巨大数值扰动下还能存活多少"。
  - 执行层面：AWQ、SmoothQuant 等工作已表明低位推理收益取决于硬件感知打包与 kernel，而非数值位宽本身。

## 2. 方法论

### 2.1 整体流水线

`Qwen3-8B FP16 → KOTMS 旋转 → E2M-ATQ 自适应三值化 → GPTQ 误差补偿 → W1.58A16 → 格感知打包 → 打包 kernel 执行`

- 目标模型：Qwen3-8B，36 层 Transformer，hidden size 4096，intermediate size 12288。
- **仅转换 252 个线性投影**：attention 的 q/k/v/o 与 MLP 的 gate/up/down。
- **未转换部分**：embedding、LM head、norm、激活、KV cache 全部保持 FP16 → 严格说是**权重-only 的 W1.58A16**，而非全张量低位图。

### 2.2 自适应三值表示

- 使用 4 个不相交的显著性掩码：`num_mask = 4`，`orders = [2, 2, 1, 1]`。
- 实测某投影的覆盖率为 0.5%、3.1%、10.0%、86.5% → **96.5% 的块只用 1 个三值平面**，约 3.6% 获得第 2 个平面。
- 紧凑表示形式：
  `b_W = (μ + α₀T₀ + α₁T₁) ⊙ M`，其中 `Tᵢ ∈ {−1, 0, +1}`
  → 第二个平面是**按显著性选择性分配**，而非均匀分配。
- 有效权重信息预算约 **1.64 bits/weight**，可写作 `B_eff ≈ (1 + f₂)·log₂(3)`，`f₂` 为获得第二平面的比例。

### 2.3 KOTMS 旋转

- 施加结构化正交变换，使权重分布更利于三值近似，同时控制激活离群值。
- 8B 运行处理 252 个投影，**实测旋转耗时 35 分钟**；在多小时的量化阶段前先做元数据检查。

### 2.4 E2M-ATQ 自适应三值化（逐掩码块）

1. 去均值：`μ = rowmean(W)`，`W_c = W − μ`
2. 阈值：`Δ₀ = 0.75 · rowmean(|W_c|)`
3. 第一支撑集：`W_c,i > Δ₀ → +1`；`W_c,i < −Δ₀ → −1`；否则 `0`
4. 用**最小二乘**选择缩放系数
5. 将残差量化到第二支撑集
6. **交替精化**：固定离散支撑，迭代更新 `μ, α₀, α₁`
- 注意：因为 `μ ≠ 0`，重建出的 FP16 张量可含大量非零浮点值 → **零值计数启发式不能作为三值来源判据**。

### 2.5 GPTQ 补偿

- 使用校准激活与近似逆 Hessian 重新分配量化误差。
- 配置：**64 个样本、2048 token 序列、seed 0、percdamp = 0.01**。
- 因保留 A16 激活，**跳过 ILA-AMP**。

### 2.6 序列化与执行

- **格感知打包**：直接持久化离散支撑集及相关参数，而非把低位数值存进 FP16 张量。
- **直接打包执行**：打包运行时直接消费打包权重（Triton 原型 kernel），替代此前的 CPU offload 路径。
