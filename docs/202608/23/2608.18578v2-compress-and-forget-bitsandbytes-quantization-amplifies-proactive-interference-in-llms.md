## 摘要
前摄干扰（PI）是大语言模型中一种已记录在案的失效模式，其中对重复覆盖值的检索会随着先前覆盖的累积而退化，这反映了人类工作记忆中的一个经典现象。训练后量化（PTQ）现在是开放权重模型的默认部署路径，但其对此失效模式的影响尚未得到测试。我们通过 bitsandbytes 评估了三种精度水平（FP16、INT8、INT4/NF4），涉及三种架构不同的指令微调模型（Qwen2.5-7B-Instruct、Mistral-7B-Instruct-v0.3、Phi-3.5-mini-instruct），并保持检索任务固定。INT4 量化在每个模型的高干扰条件下均显著降低准确率（例如，Qwen 从 81.0% 降至 68.3%），这通过配对 McNemar 检验（$p \le 2.6 \times 10^{-6}$）和涵盖所有干扰水平的混合效应回归得到确认；通常被认为安全的 INT8 在三个模型中的两个中也带来了较小但实际存在的性能损失。该效应特异于语义相似（词类型）干扰物，并在数字控制条件下符号反转，且在机制上与 INT4 下同键侵入错误的增加相关（从试验的 21.5% 升至 24.6%，$p = 4.8 \times 10^{-7}$）。后续消融实验表明，该效应源于量化的 transformer 主干，而非输出投影层。这些结果表明，bitsandbytes 4-bit 量化可能会对依赖长、可更新、语义密集上下文的应用程序施加额外代价，即使总体基准准确率看似基本不受影响。我们在 https://github.com/ShayanShahrabi/compress-and-forget 发布了我们的代码和经分词器验证的词汇表构建方法。

## Abstract
Proactive interference (PI) is a documented failure mode in large language models in which retrieval of a repeatedly overwritten value degrades as prior overwrites accumulate, mirroring a classical phenomenon in human working memory. Post-training quantization (PTQ) is now the default deployment path for open-weight models, yet its effect on this failure mode has not been tested. We evaluate three precision levels (FP16, INT8, INT4/NF4, via bitsandbytes) across three architecturally distinct instruction-tuned models (Qwen2.5-7B-Instruct, Mistral-7B-Instruct-v0.3, Phi-3.5-mini-instruct), holding the retrieval task fixed. INT4 quantization significantly reduces accuracy under high interference in every model (e.g., from 81.0% to 68.3% for Qwen), confirmed by paired McNemar's tests ($p \le 2.6 \times 10^{-6}$) and a mixed-effects regression spanning all interference levels; INT8, often assumed safe, also carries a smaller but real penalty in two of three models. The effect is specific to semantically similar (word-type) distractors and reverses sign under a numeric control condition, and is mechanistically linked to a rise in same-key intrusion errors under INT4 (from 21.5% to 24.6% of trials, $p = 4.8 \times 10^{-7}$). A follow-up ablation shows the effect originates in the quantized transformer backbone rather than the output projection layer. These results suggest that bitsandbytes 4-bit quantization can impose an additional cost on applications relying on long, updatable, semantically dense contexts, even when aggregate benchmark accuracy appears largely unaffected. We release our code and tokenizer-verified vocabulary construction method at https://github.com/ShayanShahrabi/compress-and-forget

## 1. 论文的核心问题与整体含义

- **研究背景**：前摄干扰（Proactive Interference, PI）是 LLM 的一种已知失效模式——当同一键值在上下文中被反复更新覆盖后，模型对最终值的检索准确率随覆盖次数增加而退化，这类似于人类工作记忆中的经典现象。另一方面，后训练量化（PTQ）已成为开放权重模型的主流部署方式，8-bit 和 4-bit 量化在整体基准（如 MMLU、困惑度）上通常报告几乎无损的性能。
- **核心问题**：量化与 PI 这两条研究线此前从未被连接起来——**量化是否会加剧 LLM 在前摄干扰下的检索失败？** 特别是，聚合基准无法揭示的这种细粒度行为失效，是否会被量化不成比例地放大？
- **整体含义**：如果量化确实加剧 PI，那么依赖长时、可更新、语义密集上下文的实际应用（多轮助手、文档修订追踪、对话系统追踪用户偏好）——这些恰好也是因成本原因最可能部署量化模型的场景——可能会面临比聚合基准所暗示的更高的检索失败风险。

## 2. 论文提出的方法论

- **核心思想**：将 PI-LLM 键重建（key-rebinding）范式与量化精度变量相结合——保持检索任务完全固定，仅改变模型权重加载精度（FP16 / INT8 / INT4），从而隔离量化对 PI 失效模式的因果影响。
- **任务设计**：对一个人名主语属性连续进行 k 次覆盖更新，模型需仅检索最终值。八个属性分为两组条件：
  - **语义（词类型）条件**：情绪、最喜欢的颜色、最喜欢的动物、职业——干扰项来自共享语义类别；
  - **数字（控制）条件**：温度、股价、页数——干扰项为任意整数，语义可混淆性最低。
  - 干扰水平 k ∈ {1, 2, 4, 8, 16, 32, 64, 96}。
- **配对试验设计**：对于固定的随机种子，试验序列（主语名、干扰项、顺序）在三个量化水平间完全一致，保证 FP16-vs-INT4 比较是逐试验配对的（已验证 23,075 个独特试验零失配）。
- **统计方法**：
  - **McNemar 配对检验**（主要检验）：利用试验级配对，仅使用不一致对（n₁₀/n₀₁），统计效力远高于非配对检验；
  - **Fisher 精确检验**（非配对交叉验证）与 **Mantel–Haenszel 分层检验**（跨模型合并）
  - **混合效应逻辑回归**：`correct ~ quant_mode * log2(level) + (1|model) + (1|seed) + (1|attribute)`，使用全部八个干扰水平而非选定子集，并含随机斜率鲁棒性变体。
- **误差类型分类**：重放种子确定的完整试验序列，将每个错误分类为"同键侵入"（答案等于某个较早的覆盖值）或"非匹配错误"。
- **IES 指标**：干扰耐力分数（Interference Endurance Score）——准确率-干扰水平曲线下面积（对 log₂ 尺度干扰轴做梯形积分），归一化到 [0,1]。

## 6. 论文的主要结论与发现

1. **INT4 显著加剧 PI 失效**：在三个模型的高干扰水平下，INT4 准确率一致显著低于 FP16（Qwen: 81.0%→68.3%，OR=20.0；Mistral: 44.0%→37.4%，OR=2.58；Phi: 61.8%→54.0%，OR=3.60），McNemar 检验 p ≤ 2.6×10⁻⁶。
2. **效应具有特异性**：仅在语义（词类型）干扰下出现，在数字控制条件下**符号反转**（混合效应模型中 INT4×log2(level) 交互项：词类型 β=−0.046，数字 β=+0.053），排除了"量化只是注入通用噪声"的解释。
3. **"悬崖"叙事需要修正**：INT8 在非配对检验下看似与 FP16 无差异，但配对 McNemar 检验在 Mistral（p=0.018）和 Phi（p=0.004）中恢复了真实的较小但显著的 INT8 损失；Qwen 是唯一 INT8 无显著差异的模型。实际图景是**梯度式而非干净悬崖式**的退化。
4. **机制层面**：量化显著提高同键侵入错误率（INT4 24.6% vs FP16 21.5% 的试验比例，p=4.8×10⁻⁷），且侵入值的发布时间位置在各精度间相当——量化改变的是模型混淆语义相似候选值的**频率**，而非混淆**哪个**值。
5. **效应定位在 transformer 骨干**：lm head 消融显示，额外量化输出投影层不产生统计可检测的差异（三个模型均 p=1.0，lm head 仅占总 FP16→INT4 差距的 0–2.5%）。
6. **聚合准确率掩盖效应**：整体准确率 FP16 与 INT4 仅差 1.1–2.4 个百分点，但在高干扰 + 语义可混淆条件下差距达 10–13 个百分点。

## 7. 优点

1. **配对设计的统计效力优势**：利用逐试验配对，McNemar 检验揭示了非配对 Fisher 检验无法检测的 INT8 效应——这是方法论的亮点，展示了配对设计在实际中的统计收益。
2. **严格的多层验证体系**：从每模型的小样本检验到跨模型的混合效应回归，再到随机斜率鲁棒性检查，形成了层层递进的统计确认链。
3. **特异性对照设计精巧**：数字属性控件不仅显示"无效应"，而且显示**相反符号**的效应——这是排除通用噪声解释的有力证据。
4. **机制分析直指行为证据**：通过重建确定性试验序列，将错误分类为同键侵入，直接观察到量化如何改变错误模式，而非仅停留在准确率层面的推测。
5. **诚实的局限报告**：主动报告了 Phi 在 k=16 的非单调条件、IES 计算中未重新验证的细节、lm head 默认未量化的问题，以及词汇构建早期方法的缺陷——这在研究可信度方面值得称赞。
6. **可复现性**：释放代码、分词器验证的词汇构建方法和完整试验级结果，并记录早期管线的方法论陷阱。

## 8. 不足与局限

1. **量化方法覆盖狭窄**：仅测试 bitsandbytes（LLM.int8/NF4），未覆盖 GPTQ、AWQ、EXL2、HQQ 等校准式量化器；作者也承认这些方法可能以不同方式处理 lm head 且最小化输出差异，效应是否属于 NF4 特有尚不明确。
2. **未测试激活量和 KV 缓存量化**：这些在生产服务栈中日益常见，是自然的后续方向。
3. **提示长度有限**：提示最多几百 token，远未触及 8k+ token 的长上下文区间——此前量化长上下文检索研究 [13] 提示效应可能在不同长度下呈现不同方向。
4. **模型范围受限**：仅覆盖 3.8–7B 参数范围的三个模型，未测试更大模型或校准量化默认的模型，也未测试非贪婪解码策略（如 chain-of-thought）。
5. **机制的间接性**：虽然行为证据（同键侵入 + 骨干定位）指向"表示精度细化"假说，但缺乏表征层面的直接验证（如注意力模式、残差流精度、激活分布）——这仍是从行为推断的解读而非直接测试的结论。
6. **数字控制条件的词汇不对称**：数字词汇未经过分词器单 token 过滤，1–3 token 长度不等；虽然通过分层分析降低了风险，但仍不如前瞻性过滤设计严谨。
7. **IES 计算细节未独立验证**：当属性间词汇上限不同（如 Qwen 的情绪达 k=64 但职业仅 k=32）时，IES 如何处理跨属性池化未得到验证，被作者标注为"未验证的细节"。
8. **lm head 消融的配对验证力度略低**：作者注明该消融的配对未使用主数据集那样的零失配穷尽检查，属于"动机良好但验证稍松"的伴随结果。
