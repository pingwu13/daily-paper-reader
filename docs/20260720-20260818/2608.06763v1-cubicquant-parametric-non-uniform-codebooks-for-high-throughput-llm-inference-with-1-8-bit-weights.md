## 摘要
大语言模型推理的权重量化必须在自适应重构级别与足够规则以支持高效 GPU 执行的表示之间取得平衡。均匀整数将每组限制在线性网格上。低位浮点格式使用固定的指数-尾数结构，而学习型码本以不规则解码和额外元数据为代价获得灵活性。我们提出了 CubicQuant，一种参数化非均匀标量格式，在保持稠密整数码流的同时，自适应每个权重组内的重构级别。由两个形状参数和一个尺度指定的单调三次曲线，将均匀间隔的幅度码映射到非均匀级别。该系列涵盖 1-8 位权重有效载荷，包含对称均匀整数量化作为精确特例，并且对于有效载荷宽度 B 和组大小 G，每权重的有效宽度为 B + 64/G 位。我们推导了在均匀、高斯和拉普拉斯分布下的总体失真，制定了连续和动态 A8 载体感知的拟合目标，并描述了直接打包权重的 GPU 执行。对于 G=128 的有限组，每种分布有 15,360 个样本，相对于最优裁剪的四位均匀整数量化，W4 CubicQuant 在均匀、高斯和拉普拉斯样本上的重构 RMSE 分别降低了 3.90%、13.49% 和 28.14%。相对于枚举的最佳四位有限浮点格式，降幅分别为 3.90%、9.44% 和 6.27%。初步的 H200 内核测量显示了依赖工作负载的交叉点：对于窄 GEMV，模型 dtype 执行更快，而随着行数增长，动态 A8 变得更有优势。结果确立了该格式的表示潜力和直接可执行性；下游模型质量和跨设备端到端性能仍是待评估的问题。

## Abstract
Weight quantization for large-language-model inference must balance adaptive reconstruction levels with representations regular enough for efficient GPU execution. Uniform integers constrain each group to a linear grid. Low-bit floating-point formats use a fixed exponent-mantissa structure, while learned codebooks gain flexibility at the cost of irregular decoding and additional metadata.   We introduce CubicQuant, a parametric non-uniform scalar format that preserves a dense integer code stream while adapting reconstruction levels within each weight group. A monotonic cubic curve, specified by two shape parameters and one scale, maps uniformly spaced magnitude codes to non-uniform levels. The family spans 1-8-bit weight payloads, contains symmetric uniform integer quantization as an exact special case, and has effective width B + 64/G bits per weight for payload width B and group size G. We derive population distortion under Uniform, Gaussian, and Laplace distributions, formulate continuous and Dynamic-A8-carrier-aware fitting objectives, and describe direct packed-weight GPU execution.   For finite groups of G=128 with 15,360 samples per distribution, W4 CubicQuant reduced reconstruction RMSE relative to optimally clipped four-bit uniform integer quantization by 3.90% on Uniform, 13.49% on Gaussian, and 28.14% on Laplace samples. Relative to the best enumerated four-bit finite floating-point format, the reductions were 3.90%, 9.44%, and 6.27%. Preliminary H200 kernel measurements show a workload-dependent crossover: model-dtype execution is faster for narrow GEMV, while Dynamic A8 becomes favorable as row count grows. The results establish the format's representational promise and direct executability; downstream model quality and cross-device end-to-end performance remain open evaluation questions.

## 1. 论文的核心问题与整体含义（研究动机和背景）

大语言模型（LLM）自回归推理过程中会反复从 GPU 内存中读取大型权重矩阵，降低权重存储位宽可直接缓解容量和带宽压力，尤其是在权重跨 token 复用有限的解码（decode）阶段。然而，低位宽下重构级别（reconstruction levels）的摆放位置决定了量化格式能否保留近零质量、尾部质量或两者兼顾。现有标量量化方案面临两难：

- **均匀整数量化**：支持密集打包和简单算术，但每个权重组只能使用线性网格，表达灵活性受限。
- **低位浮点格式**：通过固定指数-尾数结构重新分布级别，但动态范围偏好固定，难以适应权重局部统计特性。
- **学习型/自由码本**：可自由调整所有重构级别，但解码路径不规则、需额外元数据，与常规 GPU 矩阵乘路径不匹配。

CubicQuant 旨在填补“固定网格”与“自由码本”之间的空白：保留规则、密集的整数码流和直接 GPU 执行能力，同时通过每个权重组内的少量参数实现非均匀重构级别，兼顾统计适应性与执行效率。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

CubicQuant 是一种**参数化非均匀标量量化格式**。权重以 1-8 位整数码（payload）形式存储，每个权重组（group）额外存储一个 FP32 尺度 \(s\) 和两个 FP16 形状参数 \((a, b)\)。一个归一化的单调三次曲线 \(q(t)\) 将均匀间隔的幅度码 \(t_k\) 映射为非均匀重构级别，从而在保持整数码流密集打包的同时，让每个组自适应地调整内部级别分布。

### 2.2 关键技术细节

- **符号码设计**：对于 \(B > 1\)，最大幅度码 \(M = 2^{B-1} - 1\)，有效码为 \(\{-M, \dots, M\}\)（共 \(2^B - 1\) 个值）；保留最负的二进制补码模式并按零解码，保证精确零点和对称端点。W1 为独立二进制情形，码仅为 \(\{-1, +1\}\)。
- **参数化级别函数**：
  \[
  q(t) = t \left[ a + t(b + ct) \right],\quad c = 1 - a - b
  \]
  其中 \(t = |k|/M\)，重构值为 \(\text{sign}(k) \cdot s \cdot q(t_k)\)。该函数满足 \(q(0)=0\)、\(q(1)=1\)，零点和端点精确；严格单调性要求 \(q'(t) > 0\) 在 \([0,1]\) 上成立，可通过二次导数显式检查。
- **均匀整数量化是特例**：当 \(a=1, b=0\) 时，\(q(t)=t\)，退化为对称均匀整数量化。因此，CubicQuant 的拟合结果在元数据未舍入前至少不差于均匀整数基线。
- **元数据与有效位宽**：每个 [1, G] 权重组存储 \(G \cdot B\) 位有效载荷、一个 FP32 尺度、两个 FP16 形状参数，共 8 字节元数据。有效位宽为：
  \[
  B_{\text{eff}} = B + \frac{64}{G} \ \text{bits/weight}
  \]
- **容量与内存分析**：给出打包权重矩阵的字节数公式 \(T_W = NK(B/8 + 8/G)\)，以及相对 BF16 的压缩比 \(2/(B/8 + 8/G)\)。例如 G=256 时 W4 的字节/权重为 0.53125，压缩比约 3.76×。

### 2.3 拟合目标

- **连续参考目标**：独立地对每个权重组最小化原始域上的均方误差（MSE），同时优化码分配、尺度 \(s\) 和形状参数 \((a,b)\)，并考虑参数序列化（FP16/FP32）后的舍入影响。
- **Dynamic-A8 载体感知目标**：由于动态 INT8 激活路径实际使用的是归一化三次级别经四舍五入映射到 INT8 载体上的离散值（\(\tilde{q}(t) = \text{round}(127 q(t))/127\)），论文提出联合目标：
  \[
  L_{\text{joint}} = \frac{1}{2} L_C + \frac{1}{2} L_{A8}
  \]
  其中 \(L_C\) 是连续重构误差，\(L_{A8}\) 是 INT8 载体投影后的误差。该目标直接参与码和参数选择，并给出了最优尺度 \(s^*\) 的闭式解。
- **与数据驱动估计兼容**：格式本身不限定拟合器；可替换为激活感知、二阶 Hessian/Hessian 近似等更丰富的目标，而不改变码流和元数据结构。

### 2.4 GPU 执行

- **融合解码-计算原则**：不在全局内存中展开全精度权重，而是在每个输出 tile 中加载打包有效载荷和组元数据，生成临时的模型 dtype 或 INT8 操作数后立即参与矩阵乘。
- **模型 dtype 路径**：FP16/BF16 激活与连续 Cubic 重构级别相乘，使用 FP32 元数据运算，支持窄行 GEMV 和密集二维 tile。
- **Dynamic A8 路径**：激活按行动态量化到 INT8（使用 round-away-from-zero），权重级别映射到 INT8 载体；INT8 乘积累加为 INT32，再乘以激活尺度 \(d_x\) 和组尺度 \(s_g/127\)，保证 INT32 累加不溢出（\(G\le512\) 时最坏情况 \(|P_g|\le 8,258,048 < 2^{31}-1\)）。
- **内核选择**：基于 (B, G, M, N, K)、激活类型、路由拓扑、GPU 架构和编译器栈进行形状和架构相关的确定性选择，而非单一阈值规则。

## 6. 论文的主要结论与发现

1. **表示能力**：CubicQuant 的两次曲线族在 W3 时能够精确表示任意对称三正值自由码本，因此在高斯和拉普拉斯分布下达到 Lloyd-Max 最优；对于 W4-W8，Cubic 能封住 84.8%-96.1%（高斯）和 91.4%-96.9%（拉普拉斯）的均匀整数到自由码本之间的失真间隙。
2. **有限组增益**：在每个分布 \(G=128\) 的实验中，W4 时 CubicQuant 相对最优裁剪均匀整数的 NRMSE 降低：均匀 3.90%、高斯 13.49%、拉普拉斯 28.14%；相对最佳有限浮点格式降低：均匀 3.90%、高斯 9.44%、拉普拉斯 6.27%。有限组中均匀分布也有小幅改善，源于局部样本波动适应，而不是总体最优性。
3. **均匀分布上的理论边界**：在总体意义上，均匀分布的最优 Cubic 参数正是线性网格（\(a=1,b=0\)），因此 Cubic 无法改进总体均匀量化；有限组改进来自组内样本的偏离。
4. **浮点格式对比**：在高斯和拉普拉斯总体失真上，Cubic 在 W3-W8 优于枚举的最佳有限浮点格式（相对 MSE 降低 3.67%-21.78%）。
5. **GPU 执行可行性**：H200 上两种激活模式均能直接执行，存在 M 相关的交叉点——M=1 时 A16 更快，M 增大后 Dynamic A8 逐渐占优；持久激活载体路径不划算，被排除。
6. **核心论点**：紧凑的参数化曲线可以用规则标量位流恢复自由码本的大部分适应性，而无需放弃规则的整数码流。

## 7. 优点

- **优雅的格式设计**：将均匀整数作为特例嵌入参数族，理论上有下限保证；仅用两个形状参数实现非均匀级别，元数据开销明确且可计算。
- **理论扎实**：给出了人口失真解析表达式（包括边界、矩、单调性充分条件），推导出与 Lloyd-Max 和均匀整数之间的上下界关系，并用蒙特卡洛验证。
- **格式与估计器解耦**：CubicQuant 不绑定特定拟合算法，可与数据驱动、二阶方法结合，扩大了适用范围。
- **考虑实际执行细节**：针对模型 dtype 和动态 A8 两条路径设计了联合拟合目标，使一个 checkpoint 可同时服务两种执行模式；避免了 A8 载体投影造成的离线优化与运行时失配。
- **内存和计算模型清晰**：给出了精确的有效位宽、压缩比和整型溢出边界，便于系统级分析。
- **实验规范性**：所有方法都优化了外部尺度，保证了公平比较；解析结果和有限组实验均给出标准误差或刻度无关指标。

## 8. 不足与局限

- **缺乏下游模型质量评估**：没有报告困惑度、推理能力、任务准确率等关键指标，无法判断对真实 LLM 的影响。
- **有限组实验覆盖不足**：只有 G=128，且缺少 W1、W7；不能确定最佳组大小，也未覆盖 1-8 位全范围。
- **系统性能验证有限**：延迟数据仅来自单块 H200，且只测试了部分宽度和两种形状；跨 Ampere/Ada/Blackwell 的二进制兼容性已建立，但无性能验证。
- **未与先进量化方法对比**：没有与 AQLM、QuIP#、NF4、LUT-GEMM/FLUTE 等近年在极端压缩表现优秀的方案对比模型质量或端到端速度。
- **元数据开销较高**：有效宽度 \(B + 64/G\) 比同组均匀格点多 48/G 位；在较小 G 时开销相对明显，仅在较大 G 下可忽略。
- **不是原生 Tensor Core 类型**：权重复构仍需在 kernel 中完成，带宽收益依赖于融合执行，若重构导致额外开销可能削弱优势。
- **动态 A8 路径的局限性**：载体感知目标虽缓解了权重侧舍入，但未建模激活量化误差传播；均匀权重下的显著改善未必迁移到实际模型中的异常权重分布。
- **部分负面结果未深入探索**：持久激活载体的失败仅在一个边界上验证，未深入分析如何在寄存器/共享内存中消解同步与写回成本。

## 9. 总结

CubicQuant 提出了一个兼具理论优雅性和实用性的参数化非均匀量化框架，在保持规则整数码流和紧凑元数据的同时，通过组内三次曲线实现了显着的重构精度提升，并为模型 dtype 和动态 A8 执行提供了统一的格式支持。其在分布级实验中的优势令人信服，但缺乏下游模型质量和跨设备端到端性能验证，距离“高吞吐量 LLM 推理”的全面证明仍有一段距离。
